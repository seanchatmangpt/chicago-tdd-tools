## New constitutional cell

`standards/chicago-tdd/` is a bounded graph-to-artifact manufacturing cell:

- `O.star.toml` admits the observation and fences authority.
- `ontology.ttl` is the semantic source of truth.
- `ggen.toml` declares SPARQL extraction and generated ownership.
- `templates/` defines deterministic projections.
- `generated/` contains products and an isolated Rust verifier crate.
- `scripts/verify_ggen_standards.py` independently recomputes every generated byte, enforces gates, performs atomic writes, proves second-sync identity, and emits a receipt chain.
- `scripts/sabotage_ggen_standards.py` mutates ontology, templates, generated bytes, and broker authority; each mutation must be refused.

## Receipt v2

The evidence digest binds:

`R_pack = H(TTL, Q, T, O*, outputs, utility, tests, R_prev)`

The runtime boundary requires BLAKE3. SHA-256 is emitted only as a universally available diagnostic checksum. A verifier that cannot execute BLAKE3 reports `UNSUPPORTED`; it must not silently substitute another algorithm.

## Constitutional exclusions

The cell does not claim that arbitrary irreversible systems are reversible. It preserves reversibility while exploring graph-domain candidates, then permits bounded filesystem writes only through the verifier's atomic broker. Hooks remain intent-only. Network and arbitrary shell actuation are outside the admitted boundary.

## Standing

A local semantic and sabotage run may prove the Python cell `ALIVE`. Rust compilation and BLAKE3 receipt standing require their executors to be observed. CI is the exact-head receiver boundary.
